`/workspace/roman.py` contains two unimplemented functions:

- `to_roman(n: int) -> str` converts an integer in the range 1..3999 to a Roman numeral
  (standard subtractive notation, e.g. 4 -> `IV`, 1994 -> `MCMXCIV`).
- `from_roman(s: str) -> int` converts a valid uppercase Roman numeral back to an integer.

Both must raise `ValueError` for out-of-range integers or invalid numerals.
Implement them in `/workspace/roman.py`.
